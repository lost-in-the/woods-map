- An `include` line's note in the code view says "inlined below" again for a namespaced concern once the index records concerns by full name (Woods' fix for lost-in-the/woods#955). The note compared only the last segment of the written constant, so every namespaced include would have read "not in the index". It now matches the written name against the full name, and an include written relative to its namespace against the full name it ends. A rooted include (`include ::Canopy::MoneyColumns`) gets a note for the first time, and matches only that exact full name. The short names an index written before that Woods change still carries keep matching.
